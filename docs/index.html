    About the data

    Enrollment is final ADM. Spending is Table A7 current expenditures by source of funds; per-pupil figures are rounded to the nearest dollar. Staffing is Table A6 total positions funded from all sources.

    The NCDPI year code is the school year's ending year, which is also the state fiscal year: FY2025 = 2024–25.

    State + local + federal per-pupil differs from the total by up to $1 because each component is rounded independently.
